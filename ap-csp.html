Working well in AP CSP

Build, test, explain

  1. Plan the behavior

    State the purpose of your program and what the user will enter and see.

  2. Test deliberately

    Try typical inputs, boundary cases, and unexpected inputs. Record expected and actual results.

  3. Explain your code

    Trace how data changes and explain what each procedure contributes to the program.

Create task preparation

Practice explaining your own program and testing its behavior. Use the current official College Board instructions provided through your course for Create task requirements and permitted assistance.
